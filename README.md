## 🧠 Overview
Welcome to the **Memory Game**! This is a classic card-matching game built using **React.js**. Players flip over two cards at a time to find matching pairs, putting their memory to the test.

## ✨ Features
- 🎴 Interactive card flipping
- 🧠 Memory-based gameplay
- 🔁 New game/reset functionality
- 📱 Responsive design for all devices
- ⚛️ Powered by React Hooks (`useState`, `useEffect`)

## 🛠️ Tech Stack
- **React.js** (Frontend library)
- **JavaScript (ES6+)**
- **HTML & CSS**

## 🚀 Getting Started

### Prerequisites
- Node.js and npm installed

```bash
# Clone the repository

# Navigate to the project folder

# Install dependencies
npm install

# Start the development server
